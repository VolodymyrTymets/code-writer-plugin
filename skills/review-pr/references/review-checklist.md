# Review checklist

## Every diff

- [ ] Scope matches the ticket (C1); no drive-by refactors, renames or version bumps
- [ ] Evidence block real and complete, failure path included (B1, B2, B5)
- [ ] No suppressed check without a human-approved `// WHY:` — type-checker ignores, linter disables, skipped or `.only` tests, bypassed pre-commit (B3)
- [ ] No secret, connection string, token or client data — **including test fixtures** (A6)
- [ ] Docs updated in this PR (E1); no doc left contradicting the change (E2)
- [ ] Errors handled, not swallowed (D5); no unsafe escape hatches in the type system (D3)
- [ ] Naming matches `docs/DOMAIN_GLOSSARY.md`
- [ ] Tests exist at the level where this change can break
- [ ] Nothing written to a protected path (C3): read `.claude/rules/protected-paths*.md` for the list
- [ ] An existing pattern was followed, or an ADR explains the new one (D1)

## By kind of change

**Boundary / API change** — contract regenerated rather than hand-edited; breaking vs additive stated; every consumer found by search and updated in this PR; error responses defined, not incidental.

**Authorization-touching change** — authenticated by default; permission checked at the boundary **and** resource ownership re-checked where the data is fetched; no trust in a client-supplied identifier.

**UI change** — all four states present (loading, empty, error with retry, success); design tokens used rather than hardcoded values; keyboard reachable and labelled; no new console or log warnings; verified on the real screen, not only in an isolated harness.

**Async / background work** — idempotent handler; retry and backoff; a dead-letter or failure path; no business-critical work in a fire-and-forget timer.

**Dependency change** — one dependency per PR; justification for size, licence and maintenance; lockfile regenerated by the tool, not edited.

**Config / pipeline change** — dedicated PR; the process that consumes the file was actually run; no secret moved into a committed file.

**Performance claim** — a measurement before and after, with the method stated. No numbers, no claim.
